## 直接玩

下载 **抽象派遣局-战役版.html**，用桌面浏览器打开。图片、剧情配音、角色声音、音乐逻辑和游戏代码均已内嵌，不需要安装或联网。

建议电脑横屏，首次点击“开始新战役”。声音需要这次点击后才会开始播放。手机竖屏已做基础布局与点击验收，复杂关卡推荐横屏或电脑。

游戏是带战术暂停的实时派遣策略：正常每拍6秒，可以暂停后规划，也可以用单步推进。选择“轻松”会同时增加任务期限和关卡总时长2拍。

主动技能消耗指挥点。被动属性、角色搭配、疲劳、出发与返程都实际参与运算。预估来不及的任务仍可冒险派遣，再用技能争取时间；游戏不会把“有节目效果”算成“任务完成”。

三星需要完成全部事件、低设备损失和低城市压力。通关津贴可用于4项永久后勤改造；重复通关不会重复发钱。无需购买改造也能过关。

## 操作与存档

- 点地图或任务单选现场，点头像选择1到2名队员，再选路线并派遣。
- 点队员下方的技能按钮，对当前任务使用技能；回溯和复核作用于全局。
- `Space`：战术暂停 / 继续；剧情中进入下一格。
- `N`：单步一拍；`Esc`：暂停菜单或关闭窗口。
- 基地会恢复疲劳。人员必须完成返程才能再派，主动技能也有冷却。
- 切到后台会暂停出警。存档在当前浏览器，清理浏览器本地数据会影响存档。

## 演出与声音

美漫背景、人物和重点任务图使用内置图像生成工具制作。开场和剧情采用动态漫画镜头、转场、字幕与配音，不是长篇逐帧动画。

ElevenLabs配音覆盖开场、教学、关前剧情、尾声、失败复盘与8个角色短句。角色关键句按情绪重新导演，使用许可的中文预设声线，没有克隆真人声音。任务报告中的其他可变对白以字幕呈现。背景音乐与提示音为原创合成音。

配音文件、声线、模型、长度和校验值见 `dist/assets/audio/manifest.json`。图片生成记录与原图在 `artwork/`。会员余额、凭据和本机私有路径不属于游戏文件。

## 本地开发

使用原生HTML/CSS/JavaScript，无需安装前端依赖：

```sh
python3 -m http.server 4173 --directory dist
```

打开 `http://localhost:4173/`。

```sh
node check.mjs
node build-offline.mjs
```

`check.mjs`包含可重放的6关全清路线和技能、依赖、疲劳、往返、补救、回溯、领奖防刷、Boss反扑等检查。标准难度、默认队伍、没有永久升级也能全清。纯引擎检查不替代真实玩家测试。

原型角色和素材尚未完成相关权利核验及商业发行审核；谐音、自绘或公开仓库不代表已经取得相关真人形象等授权。
