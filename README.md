# 抽象派遣局 · 今晚谁背锅

> **早期原型 / EARLY PROTOTYPE / WORK IN PROGRESS**
>
> 这是一个很早期的游戏概念验证，目前仍是半成品。玩法、关卡、美术、台词和数值都在试验中，可能大幅修改或重做。这个仓库用于保存和评审当前进度，不代表最终品质，也不是正式发行版本。

一款以荒诞职场喜剧为方向的派遣策略试玩：挑选队员、安排任务、处理意外，再看看这单到底是谁的锅。派遣玩法参考《Dispatch》，本原型的代码、美术和文案单独制作。

![当前原型的8人阵容](./角色阵容预览.png)

## 目前做到了什么

- 8个谐音角色，各有属性和会影响派遣的技能。
- 3个班次、12个任务；每班选6人，每单派1到2人，最多同时处理两单。
- 稳妥与放飞两种处理路线，计算能力、耗时、预算、设备损失和返程。
- 文字对讲机、漫画现场、少量循环动作、任务结算和事故回放。
- 浏览器本地存档与合成提示音开关。

## 试玩

下载仓库中的 **[抽象派遣局-双击试玩.html](./抽象派遣局-双击试玩.html)**，再用桌面浏览器打开。该文件包含所需图片、代码和样式，无需安装或联网。GitHub 文件页只展示文件，需下载后再打开。

操作顺序：选6人值班 → 开始夜班 → 选任务 → 选队员与路线 → 派遣 → 推进一拍。任务结束后，队员需要再返程1拍。

## 文件结构

```text
dist/                         分文件网页与压缩图片
artwork/                      人物、场景原图及生成提示词
check.mjs                     派遣规则检查与可完成排班搜索
make-offline.mjs              生成单文件试玩
抽象派遣局-双击试玩.html        可直接下载的离线版本
角色阵容预览.png                当前阵容预览
```

人物和重点场景使用内置图像生成工具制作；提示词保存在 `artwork/`。地图及其他界面图形使用 SVG/CSS。对白为文字，提示音为简单合成音，没有真人录音或声音克隆。

## 本地开发与检查

原型使用原生 HTML、CSS 和 JavaScript，不需要安装前端依赖。在项目根目录运行：

```sh
python3 -m http.server 4173 --directory dist
```

然后打开 `http://localhost:4173/`。

```sh
node check.mjs
node make-offline.mjs
```

规则检查覆盖能力、费用、人员占用、并发上限、返程、失败、超时和角色组合，并搜索三班全部完成任务的实际排班。检查通过不等于游戏已经完成或平衡已验证。
